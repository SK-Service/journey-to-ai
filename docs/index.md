# Learning journeys

<!-- BIO: replace this paragraph with your own introduction. -->
Hands-on routes into AI, built for people who want to understand the
machinery rather than call an API. Each journey is a short working
schedule, whenever you have some time. You build the thing yourself,
from scratch, and you finish with something you can demonstrate and
feel confident about.

<div class="grid cards" markdown>

-   __[From Mathematics to LLMs](bonsai-llm/index.md)__

    A first-principles journey to building a miniature GPT — BonsaiGPT

    *16 stages · 60–120 minutes each*

    This is suitable for anyone willing to learn linear algebra, calculus and probability. This is not a tutorial for the maths required. No programming background assumed.
