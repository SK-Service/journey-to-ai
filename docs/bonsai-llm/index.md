# From Mathematics to LLMs

*A first-principles journey to building a miniature GPT — BonsaiGPT*

## Who this is for

This is suitable for anyone willing to learn linear algebra, calculus and probability. This is not a tutorial for the maths required. No programming background assumed.

## What you will have at the end

A working miniature GPT built from scratch in NumPy, rebuilt in PyTorch, with an ablation study and a portfolio you can take to an interview.

## What you need

A normal Windows laptop is enough. No GPU required — everything in this journey runs on CPU.
